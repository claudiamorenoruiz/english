How English sentences work

The most common basic structure is Subject + Verb + Complements. In English, if we add complements, the usual order is indirect object + direct object + where + when, although some verbs also use prepositions such as to or for.

Subject → my sister
Verb → gave
IO → me
DO → some notes
Where → in class
When → yesterday

Example: My sister gave me some notes in class yesterday.

This is especially useful for Spanish-speaking learners because Spanish is often more flexible, but in English word order usually carries important grammar information and sounds much more natural when it follows this pattern.
